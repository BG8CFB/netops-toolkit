netops-toolkit

网络工程师的免费 Python 工具箱 — 7 个子命令覆盖采集、定位、审计、报表、归档、拓扑

pip install netops-toolkit

info — 批量采集

netops-toolkit info

并发 SSH 采集版本/CPU/内存/运行时长，输出 CSV。

find — IP/MAC 搜索

netops-toolkit find

在备份目录中递归搜索 IP 与 MAC 地址。

locate — 全网定位

netops-toolkit locate

核心→汇聚→接入逐跳下钻，定位终端所在交换机端口。

save — 配置归档

netops-toolkit save

批量保存并拉取 running-config，按时间戳归档。

interfaces — 接口报表

netops-toolkit interfaces

解析 display interface，流量/CRC/错误率 CSV + 异常 Top10。

audit — 配置审计

netops-toolkit audit

6 条合规规则检查（telnet/SNMP 弱口令/明文 HTTP 等）。

topology — 拓扑提取 NEW

netops-toolkit topology

解析 LLDP/CDP 邻居表，输出邻接 CSV 与 Mermaid 拓扑图。
